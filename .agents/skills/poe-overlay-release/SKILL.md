# Publicação de versão

1. Confira o repositório, a versão anterior e o diff até o commit alvo. Para detalhes do fluxo, leia [Publicação](../../../docs/PUBLICACAO.md).
2. Atualize `CHANGELOG.md` e escreva as notas em português com **Novidades**, **Mudanças**, **Correções** e **Remoções**. Se uma seção estiver vazia, indique isso.
3. Gere o ZIP do commit validado. O download do README usa o nome estável `NerdMiticoJr-PoE-Leveling-Overlay.zip`.
4. Quando a publicação estiver no escopo, publique no repositório do NerdMítico Jr. e verifique o vínculo entre tag, commit, notas e download.
