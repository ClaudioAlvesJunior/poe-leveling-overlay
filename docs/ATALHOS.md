# Atalhos e ajuda

| Atalho | Ação |
| --- | --- |
| F5 | Abrir o painel da campanha |
| F6 | Gemas e links |
| F7 | Equipamento |
| Segure F8 | Árvore de passivas |
| Q / E | Trocar de árvore enquanto a sobreposição está aberta |
| Segure F9 | Layouts da zona. Use `[` e `]` para trocar de imagem |
| F10 | Iniciar, pausar ou retomar a run |
| Ctrl+F10 | Salvar a run |
| F11 | Tempos e recordes |
| Ctrl+L | Abrir ou fechar o infográfico |

O guia compacto aparece automaticamente quando o jogo está em foco. Use **Avançar** para objetivos concluídos na mesma zona e **Seguir zona** depois de um desvio.

## A árvore não aparece ou está desalinhada

Importe um PoB com uma árvore compatível no perfil ativo. Abra a árvore do jogo, afaste o zoom até o máximo e segure **F8**. Para alinhar, arraste com o botão direito enquanto mantém F8 pressionado. O pacote inclui dados da árvore do PoE 1 para builds do PoB na versão 3.29.

## Como a árvore é desenhada

O overlay usa os identificadores de nós da etapa do PoB e as posições da árvore da versão instalada. Ele desenha o plano sobre a janela e usa o seu ajuste manual para alinhar os nós. Verde marca pontos a pegar, vermelho marca pontos a remover e dourado indica joias.

Em **Preferências → Conferir passivas**, selecione um XML separado com a árvore atual do personagem. Importe o personagem no Path of Building, deixe ativa a árvore correspondente e salve a build em outro arquivo. O overlay compara as passivas e maestrias com a etapa planejada e avança para a próxima quando a comparação indicar que ela foi concluída. Depois de alocar mais pontos, gere um XML atualizado para repetir a conferência. Durante o jogo, **Q/E** continuam disponíveis enquanto você segura **F8**.

## O link pobb.in não importa

No Path of Building, copie o código de exportação ou salve a build em XML. No overlay, clique em **Importar PoB** e cole o código ou escolha o arquivo.

## Como relatar um problema

Abra um [relato](https://github.com/ClaudioAlvesJunior/poe-leveling-overlay/issues/new) com a versão do overlay, o atalho usado, o que apareceu e como reproduzir. Uma captura com os dados pessoais ocultos ajuda a localizar o problema.
