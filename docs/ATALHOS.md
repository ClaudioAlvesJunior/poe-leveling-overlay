# Atalhos e ajuda

| Atalho | Ação |
| --- | --- |
| F5 | Campanha |
| F6 | Gemas e links |
| F7 | Equipamento |
| Segure F8 | Árvore de passivas |
| Q / E | Trocar de árvore enquanto a sobreposição está aberta |
| Segure F9 | Layouts da zona. Use `[` e `]` para trocar de imagem |
| F10 | Iniciar, pausar ou retomar a run |
| Ctrl+F10 | Salvar a run |
| F11 | Tempos e recordes |
| Ctrl+L | Abrir ou fechar o infográfico |

## A árvore não aparece ou está desalinhada

Importe um PoB com uma árvore compatível no perfil ativo. Abra a árvore do jogo, afaste o zoom até o máximo e segure **F8**. Para alinhar, arraste com o botão direito enquanto mantém F8 pressionado. O pacote inclui dados da árvore do PoE 1 para builds do PoB na versão 3.29.

## O link pobb.in não importa

No Path of Building, copie o código de exportação ou salve a build em XML. No overlay, clique em **Importar PoB** e cole o código ou escolha o arquivo.

## Como relatar um problema

Abra um [relato](https://github.com/ClaudioAlvesJunior/poe-leveling-overlay/issues/new) com a versão do overlay, o atalho usado, o que apareceu e como reproduzir. Uma captura com os dados pessoais ocultos ajuda a localizar o problema.
