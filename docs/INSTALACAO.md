# Instalação e atualização

1. Instale o [AutoHotkey 1.1 de 64 bits](https://www.autohotkey.com/download/1.1/).
2. Na [versão mais recente](https://github.com/ClaudioAlvesJunior/poe-leveling-overlay/releases/latest), baixe **NerdMiticoJr-PoE-Leveling-Overlay.zip** e extraia todos os arquivos.
3. Abra o PoE 1 em modo janela sem bordas e execute `Exile UI.ahk`. Se o Windows abrir com o AutoHotkey v2, selecione o `AutoHotkeyU64.exe` da versão 1.1.
4. No jogo, pressione **F5**. A bandeja do Windows também dá acesso ao painel pelo ícone do mago.

Para atualizar, feche o overlay pela bandeja, baixe o novo ZIP e extraia sobre a instalação existente. Se você editou a tabela de preços, guarde uma cópia de `build-guide/precos.ini` antes de substituir os arquivos. Os perfis e o histórico ficam em `ini/` e `build-guide/`.
